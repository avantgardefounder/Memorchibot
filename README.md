# AI-помощник для архитекторов и прорабов (Telegram-бот)

## 1. Техническое задание (версия 1)

**Назначение.** Внутренний инструмент архитектурно-строительной компании: быстрые расчёты, проверка чертежей и фото, ориентировочные сметы и подготовка документов прямо в Telegram. В перспективе — продукт для внешних клиентов.

**Пользователи.** Архитекторы, ГИПы, прорабы, инженеры. Доступ по списку Telegram ID.

**Языки.** Русский, узбекский (латиница), английский. Язык выбирается при `/start`, AI отвечает на языке пользователя, документы составляет на языке, который попросят.

**Функции:**

| Раздел | Что делает | Как устроено |
|---|---|---|
| 📐 Расчёты | Площади, бетон (плита, ленточный фундамент, колонны, балки), арматурная сетка и масса арматуры, кирпич и раствор, кровля (односкатная, двускатная, вальмовая), толщина утеплителя, сбор нагрузок на перекрытие | AI понимает вопрос, а числа считают формулы в `calculators.py`. Цифры не «придумываются» и воспроизводимы |
| 📄 Анализ файлов | Фото объекта, скриншот чертежа, PDF проекта (до 20 МБ) → замечания и ошибки по пунктам | Сильная модель с распознаванием изображений и PDF. DWG нужно экспортировать в PDF |
| 💰 Сметы | Ориентировочная смета по прайсу с коэффициентами регионов, Word-файл сметы | Цены в `prices.json`, их заполняет компания. Без цены позиция помечается, AI цену не выдумывает |
| 📝 Документы | ТЗ, акты, письма, договоры подряда, пояснительные записки | AI уточняет данные и формирует .docx с шапкой компании и блоком подписей |

**Ограничения (честно):**
- Бот не заменяет конструктивный расчёт и экспертизу. Сейсмика, подбор сечений и несущая способность — за инженером.
- Ссылки на ШНК и КМК AI даёт «по памяти». Для точных ссылок на пункты в версии 2 нужно загрузить тексты норм в базу знаний.
- Качество проверки чертежа зависит от чёткости скана.

**Администрирование:** `/stats` — пользователи и расход токенов за 30 дней; `/reload_prices` — перечитать прайс без перезапуска; `/myid` — узнать свой ID; `/new` — очистить диалог. Лимит запросов в сутки на человека задаётся в `.env`.

## 2. Структура проекта

```
bot.py           — Telegram-логика: меню, языки, фото/PDF, отправка файлов
ai.py            — подключение к Claude, системный промпт, инструменты
calculators.py   — строительные формулы
estimate.py      — сметы по прайсу
prices.json      — прайс материалов и работ + коэффициенты регионов (ЗАПОЛНИТЬ)
docgen.py        — генерация Word-документов
db.py            — SQLite: пользователи, история, статистика
i18n.py          — тексты интерфейса RU / UZ / EN
.env.example     — шаблон настроек
Dockerfile, archbot.service — для запуска на сервере
```

## 3. Что нужно получить перед запуском

1. **Токен бота.** В Telegram откройте @BotFather → `/newbot` → придумайте имя → скопируйте токен.
2. **Ключ Claude API.** Зарегистрируйтесь на console.anthropic.com → Billing (пополнить баланс картой) → API Keys → Create Key. В Billing сразу поставьте месячный лимит расходов.
3. **Telegram ID сотрудников.** Каждый пишет боту `/myid` (или @userinfobot), вы вписываете ID в `ALLOWED_USERS`.

## 4. Хостинг — рекомендация

Бот работает постоянно, поэтому нужен сервер, а не домашний компьютер.

| Вариант | Для кого | Плюсы | Минусы |
|---|---|---|---|
| **VPS в Европе (Hetzner, DigitalOcean и т.п.), Ubuntu, 1 vCPU / 1–2 ГБ** — *рекомендую* | Старт и до сотен пользователей | Недорого (порядка 5 $/мес), стабильно, нет проблем с доступом к API | Нужно один раз настроить (15 минут по инструкции ниже) |
| VPS у узбекского провайдера | Если важно хранить данные в РУз | Оплата в сумах, локальные данные | Проверьте, что сервер стабильно открывает api.anthropic.com |
| Railway / Render (PaaS) | Если совсем не хочется сервера | Деплой из GitHub без консоли | Дороже при росте, меньше контроля |

### Запуск на VPS (Ubuntu)

```bash
apt update && apt install -y python3-venv unzip
mkdir -p /opt/archbot && cd /opt/archbot
# загрузите сюда файлы проекта (scp или unzip архива)
python3 -m venv venv
venv/bin/pip install -r requirements.txt
cp .env.example .env && nano .env        # вписать токены и ID
venv/bin/python bot.py                    # проверка: напишите боту /start, затем Ctrl+C
cp archbot.service /etc/systemd/system/
systemctl enable --now archbot            # автозапуск и перезапуск при сбоях
journalctl -u archbot -f                  # смотреть логи
```

Через Docker: `touch bot.db && docker build -t archbot . && docker run -d --restart=always --env-file .env -v $(pwd)/bot.db:/app/bot.db archbot`.

## 5. Бюджет на AI

Оплата — за объём текста (токены), абонентской платы нет. Чтобы держать расходы под контролем, бот уже:
- использует **быструю дешёвую модель** (`MODEL_FAST`) для вопросов, расчётов и смет, а **сильную** (`MODEL_SMART`) — только для фото, PDF и документов;
- держит в памяти только 12 последних сообщений, без картинок;
- ограничивает число запросов в сутки (`DAILY_LIMIT`).

**Рекомендация на старт:** пополнить баланс на 20–50 $, поставить такой же месячный лимит в консоли и через 2–3 недели посмотреть `/stats`. Самые дорогие запросы — многостраничные PDF. Актуальные цены моделей: https://www.anthropic.com/pricing

## 6. Как заполнить прайс

Откройте `prices.json` и вместо `0` поставьте цены в сумах (цены для Ташкента, регионы считаются коэффициентами). Обновите поле `updated` и отправьте боту `/reload_prices`. Новые позиции добавляются по образцу.
